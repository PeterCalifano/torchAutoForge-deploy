## Project Overview

`torchAutoForge-deploy` is a C++/CUDA library for deploying machine learning models via ONNX Runtime. It provides a `CInferenceManager_ORT` class wrapping ORT sessions, with optional CUDA/OptiX GPU acceleration and optional Python/MATLAB bindings via gtwrap.

## Build Commands

The primary interface is `build_lib.sh`:

```bash
./build_lib.sh                        # RelWithDebInfo build, configure + build + test
./build_lib.sh -t debug               # Debug build
./build_lib.sh -t release -i          # Release build + install
./build_lib.sh -r                     # Rebuild only (skip CMake configure)
./build_lib.sh --clean -t debug       # Clean reconfigure
./build_lib.sh -N                     # Use Ninja generator
./build_lib.sh -j 8                   # Parallel jobs
./build_lib.sh --skip-tests           # Skip test execution
./build_lib.sh -D ENABLE_CUDA=ON      # Pass extra CMake definitions
./build_lib.sh -p                     # Enable Python wrapper (requires gtwrap)
./build_lib.sh -m                     # Enable MATLAB wrapper
```

Manual CMake:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel $(nproc)
ctest --test-dir build --output-on-failure -j $(nproc)
```

## Running Tests

```bash
# All tests
ctest --test-dir build --output-on-failure -j $(nproc)

# Single test by name pattern
ctest --test-dir build -R testTemplate -V
ctest --test-dir build -R CInferenceManager_ORT -V

# List available tests
ctest --test-dir build --show-only
```

Tests use Catch2 v3 (auto-fetched if not found). New test files named `test*.cpp` in a subdirectory of `tests/` are auto-discovered by `add_tests()` in `cmake/cmake_utils.cmake`.

## Key CMake Options

| Option | Default | Description |
|--------|---------|-------------|
| `ENABLE_CUDA` | OFF | CUDA support (requires CUDA 12.0+) |
| `ENABLE_OPTIX` | OFF | OptiX acceleration (requires CUDA) |
| `ENABLE_TESTS` | ON | Build and run tests |
| `SANITIZE_BUILD` | OFF | Enable sanitizers |
| `WARNINGS_ARE_ERRORS` | OFF | `-Werror` |
| `autoforge_deploy_BUILD_PYTHON_WRAPPER` | OFF | gtwrap Python bindings |
| `autoforge_deploy_BUILD_MATLAB_WRAPPER` | OFF | gtwrap MATLAB bindings |

## Architecture

### Core Module: `src/inference/onnx_runtime/`

- **`onnxruntime_inference_tools.hpp/.cpp`** - `CInferenceManager_ORT` class: initializes ORT environment/sessions, loads ONNX models, runs typed inference. Currently under active development (see `TODO` at project root).

### Auxiliary: `src/auxiliary/`

- **`common_defs.h`** - `SInputOutputSpecs<>` template struct defining tensor I/O (names, shapes, types)
- **`common_ops.h`** - `AccumProduct()` utility for computing tensor element counts
- **`images_prepro.h`** - OpenCV-based image preprocessing helpers

### Standalone Programs: `src/programs/`

- `get_available_providers` - lists ORT execution providers at runtime
- `run_ort_inference` - placeholder inference runner

### Bindings

Python/MATLAB wrappers are generated by gtwrap from `src/wrap_interface.i` and `src/inference/inference.i`. Enable via `-p`/`-m` flags or CMake options.

### Config Header

`src/config.h.in` is configured by CMake to produce a version header with `PrintVersion()` / `GetVersionString()`.

## Compile Flags by Build Type

- **Debug**: `-Og -g -fmax-errors=3` + full warnings + optional sanitizers
- **Release**: `-O3 -fmax-errors=1`
- **RelWithDebInfo** (default): `-O2 -g` + safety warnings (`-Wnull-dereference`, `-Wfloat-equal`, `-Wconversion`, `-Wnon-virtual-dtor`)

All builds use `-Wall -Wextra -Wpedantic`. Sanitizers activated by `-DSANITIZE_BUILD=ON`.

## Required Dependencies

- **Eigen3** ≥ 3.4
- **ONNX Runtime** (system install expected; set `OnnxRuntime_DIR` if non-standard)
- **Optional**: OpenCV, CUDA Toolkit 12.0+, OptiX, gtwrap
